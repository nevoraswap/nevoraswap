Nevora Swap — твой боевой мод

Fabric мод для Minecraft 1.21.4 с автосвапом, быстрым использованием предметов и системой друзей. Работает на любых серверах.

Возможности мода

⚡

AutoSwap

Автоматическая замена предметов в левой руке. Меняет тотемы на сферы и обратно.

Настраиваемый бинд
💨

FT Helper

Быстрое использование предметов из хотбара по отдельным биндам.

5 настраиваемых биндов
🌪️

Wind Helper

Комбо-связка для булавы. По бинду: камера вниз → берёт заряд ветра → кидает под ноги → прыгает → берёт булаву.

Булава + заряд ветра
🍑

Chorus Helper

Умное поедание хоруса. Зажимаешь бинд — мод находит хорус в инвентаре и начинает есть.

Зажать и держать
🪶

Fly Helper

При надевании элитр автоматически отправляет команды /fly и /speed 10.

Автоматически
👥

Friends System

Система групп через облако. Приглашайте тиммейтов, зелёные теги над головами.

Теги + расстояние
🔒

Защита HWID

Лицензия привязывается к вашему ПК. Один аккаунт — одно устройство.

Безопасность
📊

HUD

Отображение ника, FPS, пинга и координат на экране.

❓ FAQ

🔹 Как установить мод?
1. Установите Fabric Loader для 1.21.4
2. Скачайте Fabric API и поместите в папку mods
3. Скачайте Nevora Swap и поместите в папку mods
4. Запустите игру с профилем Fabric
🔹 Как активировать мод?
При первом запуске мод покажет код. Введите его в Профиль → Активация мода.
