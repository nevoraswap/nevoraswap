Nevora Swap — твой боевой мод

Fabric мод для Minecraft 1.21.4 с автосвапом, быстрым использованием предметов и системой друзей. Работает на любых серверах.

Возможности мода

⚡

AutoSwap

Автоматическая замена предметов в левой руке. Меняет тотемы на сферы и обратно по нажатию бинда. Поддерживает боковые кнопки мыши (M4, M5). Настройка: игнорировать обычные тотемы (использовать только зачарованные).

Настраиваемый бинд
💨

FT Helper

Быстрое использование предметов из хотбара по отдельным биндам. Трапка (незеритовый лом), Дезориентация (око энда), Явная пыль (сахар), Пласт (сушеный ламинарий), Снежок. Моментальный свап → использование → возврат на предыдущий слот.

5 настраиваемых биндов
🌪️

Wind Helper

Комбо-связка для булавы. По бинду: камера вниз → берёт заряд ветра → кидает под ноги → прыгает → берёт булаву. Если булавы нет — остаётся на заряде ветра. Задержки между действиями для естественности.

Булава + заряд ветра
🍑

Chorus Helper

Умное поедание хоруса. Зажимаешь бинд — мод находит хорус в инвентаре, перемещает в хотбар и начинает есть. Отпускаешь — всё возвращается обратно. Открывает инвентарь для безопасности (анти-флаг).

Зажать и держать
🪶

Fly Helper

При надевании элитр автоматически отправляет команды /fly и /speed 10. Больше не нужно прописывать их вручную при каждом переключении режима.

Автоматически
👥

Friends System

Система групп через облако. Приглашайте тиммейтов (/ninvite), принимайте приглашения (/naccept). Зелёные теги над головами тиммейтов видны через стены на любом расстоянии с указанием дистанции. Размер тегов адаптивный.

Теги + расстояние
🔒

Защита HWID

Лицензия привязывается к вашему ПК. Один аккаунт — одно устройство. Защита от передачи мода третьим лицам.

Безопасность
📊

HUD

Отображение ника, FPS, пинга и координат на экране. Effect HUD предупреждает об окончании эффектов (Сила 3-5, Скорость 3). Все элементы можно перетаскивать мышкой в чате.

Настраиваемый

❓ FAQ

🔹 Как установить мод?
1. Установите Fabric Loader для 1.21.4
2. Скачайте Fabric API и поместите в папку mods
3. Скачайте Nevora Swap и поместите в папку mods
4. Запустите игру с профилем Fabric
🔹 Как активировать мод?
При первом запуске мод покажет код. Введите его в Профиль → Активация мода.
🔹 Мод не работает?
Убедитесь что установлен Fabric API для 1.21.4. Выключите VPN и программы обхода блокировок.
